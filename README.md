# Deepfake Audio Detection

## About the Project
Deepfake Audio Detection is a group mini project developed to identify whether an audio recording is real or artificially generated or manipulated.

The project uses audio preprocessing and deep learning techniques to analyse audio signals and classify audio samples.

## Project Type
Academic Group Mini Project

## Technologies Used
- Python
- Flask
- Convolutional Neural Network (CNN)
- PyTorch
- Librosa
- SQLite
- HTML, CSS and JavaScript

## Key Features
- Audio input and processing
- Audio preprocessing
- Deep learning-based audio classification
- Prediction result generation
- Database storage of results

## Project Structure
- `app.py` – Main Flask application
- `cnn_train.py` – CNN model training
- `cnn_predict.py` – Audio prediction
- `preprocess.py` – Audio preprocessing
- `evaluate.py` – Model evaluation
- `view_db.py` – Database viewing
- `cnn_model.pth` – Trained model
- `requirements.txt` – Python dependencies

## Project Status
Group mini project.
